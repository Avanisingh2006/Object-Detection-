AI Object Detection using YOLOv8 & Gemini

A Python project that uses *YOLOv8* to detect objects and *Google Gemini AI* to generate a short natural-language description of the detected scene.

## Features
- Real-time object detection
- AI-generated scene descriptions
- Webcam support
- Built with Python, YOLOv8, OpenCV, and Gemini AI

## Tech Stack
- Python
- YOLOv8
- OpenCV
- Google Gemini AI

## Run

bash
pip install -r requirements.txt
python main.py


> API keys are securely stored using a .env file.
